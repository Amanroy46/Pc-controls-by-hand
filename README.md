# Real-Time Hand Gesture-Based PC Control

A Python computer vision project that explores controlling PC interactions through hand gestures captured by a webcam.

## Features

* Webcam-based hand gesture recognition.
* Gesture-based PC interaction.
* Mouse control features supported by the implemented code.

## Technology Stack

* Python
* OpenCV
* MediaPipe
* PyAutoGUI

*Confirm these dependencies against the actual source code before publishing.*

## How It Works

1. Capture video from the webcam.
2. Process video frames to identify hand gestures.
3. Map recognized gestures to supported computer actions.
4. Execute the corresponding action through the PC-control interface.

## Getting Started

### Prerequisites

* Python installed on your system.
* A working webcam.
* The required Python libraries installed.

### Installation

Clone the repository:

```bash
git clone https://github.com/Amanroy46/Pc-controls-by-hand.git
cd Pc-controls-by-hand
```

Install dependencies after adding a verified `requirements.txt`:

```bash
pip install -r requirements.txt
```

Run the application using the actual entry-point filename and instructions for your project.
